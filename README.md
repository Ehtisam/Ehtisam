# Ehtisam

I build things for my own projects: a Spotify client for the terminal, a markup language for writing, Obsidian plugins, a music player and a game translation. My stories and worlds are on my site, [solshuenshia.com](https://solshuenshia.com).

## Open source

- **[sotto](https://github.com/Ehtisam/sotto)**: A Spotify player for the terminal, written in Go. It plays the music itself through Spotify Soloist and can also control the Spotify app or a phone. It has synced lyrics, themes, a command line and an MCP server for AI assistants.
- **[Mürekkep](https://github.com/Ehtisam/murekkep)**: My own markup language (.mrk). It has a parser, a specification, tests and an editor that runs in the browser. It also has plugins for Obsidian and Sublime Text. [Try the editor](https://ehtisam.github.io/murekkep/editor.html)
- **[Spotify Playlist Sync](https://github.com/Ehtisam/spotify-playlist-sync)**: An Obsidian plugin that saves Spotify playlists as separate notes with their cover, name, description and track list. It keeps them updated on a schedule.
- **[Asura's Wrath Turkish Patch](https://github.com/Ehtisam/asuras-wrath-tr)**: A Turkish translation for the Xbox 360 version of the game. The tools that apply the patch are written in Python.
- **[Soleil](https://github.com/Ehtisam/soleil-player)**: A retro-futuristic music player I am building on a Raspberry Pi Zero 2 W. The repository has SoleilOS, the software that runs on it, and the hardware documents.

## Closed source

- **NODACS**: A Counter-Strike style arena plugin for Minecraft 1.21 servers. Two teams (T and CT) face each other on the same map. It covers arena setup, queueing, spectator mode and team chat. Written in Java.
- **[solshuenshia.com](https://solshuenshia.com)**: My personal site, built with Astro and bilingual in Turkish and English.
- **Cardo**: A terminal panel (TUI) that manages the site's content, built on Markdown and git.
- **Dark Firmament**: Mobile apps written in Flutter. Budget tracks spending, Score keeps score in card and dice games, Shift is a shift work calendar and Garden is a moon gardening calendar with plant care reminders. They are being prepared for Google Play.
